# Lavame Plus — landing page para Vercel

Projeto estático, sem framework e sem build.

## Publicar
1. Suba esta pasta para um repositório GitHub.
2. Na Vercel, crie um projeto e importe o repositório.
3. Framework Preset: Other.
4. Build Command: deixe vazio.
5. Output Directory: deixe vazio.
6. Deploy.

## Antes de divulgar
- Confirme telefone/WhatsApp: (21) 97951-1720.
- Confirme horários do rodapé.
- Confirme áreas atendidas.
- Quando tiver a URL final, adicione `canonical` e `og:url` no `<head>`.
- Cadastre a URL final no Perfil da Empresa no Google.
- Depois configure Google Search Console.


## Teste local
Abra `index.html` com Live Server. Esta versão usa caminhos relativos e funciona mesmo quando a pasta está dentro de outro workspace.
